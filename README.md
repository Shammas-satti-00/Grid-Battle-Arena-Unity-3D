# Grid Battle Arena - Unity 3D

## Description
Grid Battle Arena is a simple 2D grid-based game developed in Unity. The game features a 5x5 grid where two players take turns tapping tiles to claim them. Each player is represented by a unique color (red and blue), and the objective is to dominate the grid by strategically selecting tiles.

## Gameplay & Functionality
- The game supports two players who alternate turns.
- Players tap/click on unoccupied tiles to claim them with their color.
- The current player's turn is displayed on screen.
- Once a tile is claimed, it changes color and cannot be selected again.
- The game detects when a player wins by forming a continuous line (horizontal, vertical, or diagonal) or when the grid is fully occupied resulting in a draw.
- When the game ends (win or draw), further moves are disabled until the game is restarted.
- Players can restart the game to play again.
- The UI provides feedback about the game state including current turn and game result.

## How to Run
- Open the project in Unity Editor (version compatible with Unity 2D projects).
- Press the Play button to start the game.
- On mobile or desktop, tap/click tiles to play.

## Project Status
This project is a functional prototype with core gameplay implemented and basic UI. Additional polish like tile highlights, animations, and mobile optimizations are planned.
